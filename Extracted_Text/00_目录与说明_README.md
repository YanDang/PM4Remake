## 1. 解密与逆向工程说明

- **封包格式 (`GCAX` / `GCA3`)**：主游戏 `PrincessMaker4+\script` 与特典 `PM4Omake\script` 均采用 `GflGCACryptograph` 自定义流密码加密（基于改造版 MT19937 伪随机数生成器，每 4 字节消耗 8 个随机数进行移位异或与加减运算）。
- **封包密钥**：逆向 `PrincessMaker4+.exe` (`0x404eca` / `0x50cc98`) 提取出硬编码密码为 `"kf"`（索引头密钥为 `"kfHeader"`，子文件密钥为 `"kf" + 文件名`）。所有解包文件均通过 100% CRC32 校验。
- **脚本字节码 (`G2CD0461` / `.g2`)**：剧本编译为自定义栈虚拟机字节码，内嵌字符串经 `(byte - index - byte_length) & 0xFF` 逐字节混淆后以 `UTF-16LE` 存储。
- **剧情结构还原**：通过反编译全量字节码指令流（`room.g2` 共 405,528 条指令、`omake.g2` 共 16,920 条指令），完整还原了 **说话人姓名 (`syscall 8448`)**、**表情状态 (`emotion`)**、**语音文件 (`syscall 5664`)**、**多段行内变量拼接台词 (`op=0x01` + `syscall 4106`)**、**表情符号 (`[♥]`, `[？]`, `[！]`, `[汗]`, `[怒]`)** 以及 **分支选项与跳转目标标签 (`syscall 4495/4487`)**。
- **简体中文与自定义女儿姓名**：所有提取文本已统一转换为简体中文，女儿默认名“派翠西亚”已替换为玩家自定义名字占位符 `{daughter_name}`，姓氏“海斯”已替换为 `{secondname}`。
